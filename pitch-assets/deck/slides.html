Retenqo · Private Memory OSArchitecture · private by default
Architecture of the proposed solution
The local commitment store is the product boundary.
INPUT LAYER

WhatsApp · Calendar · LMS · mail
NotificationListener, permitted screen capture, voice.

Raw sources stay on the phone. Only allowed inputs enter the pipeline.
MEMORY LAYER

ML Kit → RulesExtract → Qwen3.5
Normalize into Room cards; embed for local retrieval.

Persistent text card; temporary pixels deleted after extraction.
RESPONSE LAYER

Retrieve → filter → route → cite
Brief, Ask, due list, mark-done, conflict flag.

The generator sees retrieved cards, not an entire chat history.

Rules path

Dates, amounts, mark-done, deterministic fallback.

Daily phone path

Qwen3.5-2B Q4_K_M for 6 GB devices.

iQOO flagship path

Qwen3.5-4B → GGUF → llama.cpp → QNN / Hexagon delegate.

Safety path

No match → refuse. Conflict → keep both and surface it.

Privacy contract: source data and inference remain local; the iQOO path uses flagship headroom for faster, richer on-device reasoning without changing the evidence contract.

Why this performs well on iQOO

The high-end path does not make every task bigger. It uses the phone’s headroom selectively:

  • Rules handle predictable work.
  • 2B handles extraction and short Ask.
  • 4B handles multi-card conflict.
  • Whisper handles voice capture.
  • Embeddings keep retrieval local.

Core reliability rule

Retrieve + cite + extractive fallback beats a bigger model with no evidence.
